    <div class="lbl">FAQs: reviews</div>

    <details><summary>How do performance reviews work?</summary>

      <p>When your team member submits their <b>Self-Evaluation</b>, you'll get a Manager Evaluation item in your <b>Inbox</b>. You can also open <b>My Team's Performance Reviews</b> to see where each direct report is in the process. If the current step says <b>Complete Manager Evaluation</b>, select that employee's review to begin.</p></details>

    <details><summary>Can I complete my evaluation before the employee finishes their self-evaluation?</summary>

      <p>Employees start the process by answering the <b>Self-Evaluation</b> questions, and only they can see their responses while it's in progress. Share deadlines with your team so you have enough time to complete <b>Evaluations</b> for your direct reports.</p></details>

    <details><summary>How can I send a review back to an employee?</summary>

      <p>If an employee needs to revise after selecting <b>Submit</b>, you can send it back. In the <b>My Team Management</b> app, go to <b>Manager Reports by Category</b> → <b>Performance</b> → <b>My Team's Performance Reviews</b>. Find the review, open its actions menu, and select <b>Business Process</b> → <b>Manual Send Back</b>.</p></details>

    <details><summary>How can my manager view my direct reports' reviews?</summary>

      <p>Your manager isn't part of the formal review steps, but can run the <b>Employee Review by Supervisory Organization</b> report:</p>

      <ol>

        <li>Type the report name in the Workday search box.</li>

        <li>Select the organization by typing in the manager's name.</li>

        <li>To see reviews for the whole organization, check <b>Include Subordinate Organizations</b>.</li>

      </ol></details>

    <div class="lbl">FAQs: goals</div>

    <details><summary>What's the difference between the Personal Goals, Goal Details, and Organizational Goals tabs?</summary>

      <p><b>Personal Goals</b> shows goals you create for yourself and goals your leader creates for you. <b>Goal Details</b> shows the same goals in a table view. <b>Organizational Goals</b> shows goals set at the college or unit level.</p></details>

    <details><summary>What's the difference between deleting a goal and marking it "On Hold"?</summary>

      <p><b>Remove</b> permanently deletes the goal from Workday, and it can't be recovered. Changing the status to <b>On Hold</b> moves the goal to the bottom of the Personal Goals tab, where you can update it later.</p></details>

  const wp = document.getElementById('wp');

  wp.querySelectorAll('[data-go]').forEach(el => el.addEventListener('click', () => {

    const t = document.getElementById(el.dataset.go);

    if (t) t.scrollIntoView({ behavior: 'smooth', block: 'start' });

  const secs = [...wp.querySelectorAll('.sec')].filter(s => s.id);

  const q = document.getElementById('q'), msg = document.getElementById('qmsg');

  q.addEventListener('input', () => {

    const v = q.value.trim().toLowerCase();

    let n = 0;

    secs.forEach(s => {

      const hit = !v || s.textContent.toLowerCase().includes(v);

      s.classList.toggle('hidden', !hit);

      if (hit) n++;

      s.querySelectorAll('details').forEach(d => { d.open = !!v && d.textContent.toLowerCase().includes(v); });

    });

    msg.textContent = v ? (n ? n + ' section' + (n > 1 ? 's' : '') + ' match' : 'No matches. Try another word.') : '';

  });
